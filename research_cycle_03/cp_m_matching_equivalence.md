## 2. Audited model and scope

Put `n=2m`, let the ground set be `U`, and identify a balanced coloring with
a plus set `P subseteq U` of size `m`.  An ordered perfect matching is a
sequence of disjoint pairs

`(e_1,...,e_m)` with `union_j e_j=U`.

It crosses `P` when every `e_j` has one endpoint in `P`.  By the independently
rechecked consecutive-pair characterization, the even prefixes

`emptyset, e_1, e_1 union e_2, ..., U`

form the contraction of a 1-balanced maximal chain exactly when the matching
crosses `P`.  Either orientation inside each crossing pair gives a compatible
odd intermediary.

This attack uses no conclusion from CF-LOGGAP.  The objects here are fixed
deterministic subset families and pair-labelled DAGs; there is no greedy
frontier, filtration, random order, gap tail, or single-consumption rule.
The exact `N(10)=35` computation is also not a dependency of the
one-factorization counterexample.

The literature boundary is inherited from
[`literature_novelty_audit.md`](literature_novelty_audit.md).  FLSY explicitly
introduced the pair-labelled nondeterministic read-once open-path program, so
the main matching-program viewpoint is prior art.  Classical switching,
permutation, and routing networks are adjacent objects, but their hardware
counts do not count the literal used-variable supports required here.  The
canonical normalization below was not located as a separately stated result;
that search outcome gives it status `NOVELTY UNCLEAR`, not novelty.

## 3. Independent audit of the canonical-support quotient

### 3.1 Exact hypotheses

Consider a finite directed acyclic graph with source `s` and sink `t`.  Every
edge is labelled by a two-element subset of `U`.  Assume:

1. every vertex and edge is **live**, meaning that it lies on an `s`--`t`
   path (dead material may first be deleted);
2. every `s`--`t` path has exactly `m` edges; and
3. the program is syntactically read-once: the `m` pair labels on every
   `s`--`t` path are pairwise disjoint.

Thus every full path uses all `n` variables and is an ordered perfect
matching.  On a coloring, an edge is open exactly when its pair crosses the
color cut.

These hypotheses are essential.  In particular, an informal device that
forbids repeated variables by remembering path history outside its graph is
not a syntactic read-once branching program and does not satisfy the proof.

### 3.2 Unique-support lemma

**Claim `CPM-SUPPORT`.** Every live vertex `v` has a unique used-variable
support `S_v`: all directed paths from `s` to `v` use exactly the same ground
elements.

**Proof.** Let two source-to-`v` prefixes use supports `A` and `B`.  Fix any
live `v`-to-`t` suffix and call its support `D`.  Concatenating this suffix
with either prefix gives a full path.  Syntactic read-once gives

`A intersect D = B intersect D = emptyset`.

Each concatenated path consists of `m` disjoint two-element labels, so it
uses all of `U`.  Hence

`A union D = U = B union D`,

and `A=B=U minus D`.  This argument also shows that an edge `u -> v` with
label `e` satisfies

`S_v = S_u union e` and `S_u intersect e=emptyset`.  `square`

Vertices with the same support may be merged.  A prefix entering the merged
state uses `S`, and any suffix leaving it uses `U minus S`; splicing therefore
cannot repeat a variable.  Every quotient edge still adds its forced
two-element support difference.  The quotient is a layered canonical
even-subset DAG.  Conversely, such a DAG is immediately a pair program.

Therefore, under vertex counting and the three displayed hypotheses, the
minimum FLSY-program vertex count equals the minimum canonical-support vertex
count.  This is a normalization statement only; it does not identify that
count with `N(n)`.

### 3.3 Accounting for odd intermediaries

Let `Q(n)` be the minimum number of distinct even support vertices in a
canonical pair-DAG that has an open source-to-sink path for every balanced
cut.  Contracting any 1-balanced-chain family gives

`Q(n) <= N(n)`.

Conversely, let a canonical DAG have `V` vertices and `E` distinct edges.
Choose one of the two possible odd intermediary subsets for every edge and
take the union of all chosen intermediaries with the even vertices.  Every
open path then expands to a selected maximal chain, so

`N(n) <= V+E`.

There is at most one useful edge for each ordered pair of support vertices,
and each support has at most `binom(n,2)` possible inclusion-by-two
successors.  Hence, for an optimum `V=Q(n)`,

`Q(n) <= N(n) <= Q(n) + min(Q(n)^2, Q(n) binom(n,2)).`

In particular the literature report's weaker displayed inequality

`Q(n) <= N(n) <= Q(n)+Q(n)^2`

is correct.  It is a polynomial-existence equivalence, not an equality of
exact finite minima: `N` charges distinct odd subsets, and one odd subset may
back several even-to-even edges.

## 4. Exact prefix-union invariant

The quotient proof leads to an exact formulation of what matching-state
compression must accomplish.

Let `A` be a collection of **oriented ordered** perfect matchings.  Treat an
orientation as an order of the two elements inside every pair, concatenate
the pairs, and let `Pref_all(A)` be the union of all `n+1` literal subset
prefixes of all resulting permutations.  Call `A` cut-covering if every
balanced cut is crossed by at least one member, ignoring its orientations.

Then

`N(n) = min_A |Pref_all(A)|`,

where the minimum is over cut-covering oriented ordered-matching
collections.

For the forward inequality, the displayed prefix union is itself a valid
set family.  For the reverse inequality, take an optimum family `X`; for
each of the finitely many balanced colorings choose one witness chain in
`X`.  The oriented ordered matchings induced by those chains are
cut-covering and their entire prefix union is contained in `X`.

There is an even-state version.  For a collection `B` of ordered (but
unoriented) perfect matchings, let `Pref_even(B)` contain the unions of its
first `j` pairs, for `0<=j<=m`.  Then

`Q(n) = min_B |Pref_even(B)|`

over cut-covering collections `B`.  A collection builds the union-of-prefix
canonical DAG.  In the other direction, delete dead vertices from an optimum
canonical DAG and take all its source-to-sink paths; every live support occurs
as a prefix on at least one such path.

These identities are reductions, not upper bounds.  They isolate the only
possible compression in this model:

> different ordered matchings may share a state exactly when they have the
> same literal union of already used pairs (and, for `N`, the same next odd
> prefix).

A fixed ordered matching crosses exactly `2^m` of the `binom(2m,m)` signed
balanced colorings: orient each of its `m` pairs independently toward the
plus side.  Consequently every covering matching menu contains at least

`ceil(binomial(2m,m)/2^m)`

members, which is exponential in `m`.  This does **not** lower-bound its
prefix union: exponentially many matchings might still share far fewer
literal supports.  Confusing those two counts is precisely the accounting
error CP-M must avoid.

## 5. A quadratic interval family: hybrid success and exact obstruction

### 5.1 A corrected warning about seed menus

For a menu of `t` oriented ordered perfect matchings, define `X(menu)` to be
the literal union of their maximal-chain prefixes.  Its exact size is the
cardinality of that set union, and always

`|X(menu)| <= 2+t(n-1)`;

only the empty and full states were removed from the per-path overcount.  If
the listed matchings cover every balanced cut, then `X(menu)` is valid,
because a crossing matching supplies an explicitly selected chain.

The converse is false.  A set family supplies every inclusion-by-one edge
between selected subsets, including edges not consecutive on any seed path.
Prefixes from different menu members can therefore splice into a new hybrid
maximal chain.  This distinction invalidates any lower bound that merely
counts how many cuts the **listed** matchings cover.

The exact prefix-union identity in Section 4 is unaffected: if a seed union
is valid only because of hybrid paths, add one such already-selected witness
chain for every coloring to the path collection.  Its prefix union does not
grow.  What fails is only the claim that an arbitrary seed menu lists all
paths induced by its subset union.

### 5.2 Cyclic one-factorization seeds and literal accounting

Write

`U = Z_q union {infinity}`, where `q=2m-1`.

For every `r in Z_q`, define

`M_r = {{infinity,r}} union {{r+i,r-i}: 1<=i<=m-1}`,

with arithmetic modulo `q`.  These `q=n-1` matchings partition the edges of
the complete graph.  The infinity edge determines `r`; for a finite edge,
its unique midpoint modulo odd `q` determines `r`, and its nonzero signed
distance determines one unordered pair in the displayed range.

Give `M_r` the oriented order

`r, infinity, r+1, r-1, r+2, r-2, ..., r+(m-1), r-(m-1)`.

Let `RR_n` be the union of the literal prefixes of these `q` permutations.
At rank one its states are the singletons `{r}`.  At every rank `k` with
`2<=k<=n-1`, its states are exactly

`{infinity} union I`,

where `I` ranges over the `q` cyclic intervals of length `k-1` in `Z_q`.
Indeed, at even rank `2j` the seed centered at `r` has finite interval
`{r-(j-1),...,r+(j-1)}`.  At odd rank `2j+1` for `1<=j<=m-1`, it has finite
interval `{r-(j-1),...,r+j}`.  Rank one is the separate state `{r}`.

Proper cyclic intervals with different starting positions are distinct.
Ranks distinguish subsets of different sizes, while all paths share the two
endpoints.  Therefore the exact **distinct-subset** count is

`|RR_n| = 2+(n-1)^2`.

This is a genuine quadratic accounting theorem for the fixed family.  It
does not yet establish coverage.

### 5.3 Exact interval/deque characterization

Reverse every sign if necessary so that `infinity` is minus.  The `q` finite
points then form a cyclic binary word with `m` pluses and `m-1` minuses.

Every selected chain in `RR_n` must:

1. start with a plus singleton `r` and then add the minus point `infinity`;
2. maintain one cyclic interval of finite points; and
3. enlarge that interval by one point at either endpoint on each subsequent
   step.

At every even rank the finite interval has odd length and must have sign sum
`+1`.  Thus each two-step enlargement must add one plus and one minus.  In
reverse, a chain exists exactly when the cyclic word can be reduced to a
single plus by repeatedly deleting an opposite-sign pair in one of three
ways: the first two symbols, the last two symbols, or the first and last
symbols of the current linear interval.  The first deletion may use any cut
of the cycle.

Equivalently, for a linear word `w` of odd length define

```text
G(w) = true                                      if w is the one-letter word 1;
G(w) = (w[0]!=w[1]   and G(w[2:]))
    or (w[-2]!=w[-1] and G(w[:-2]))
    or (w[0]!=w[-1]  and G(w[1:-1]))             otherwise.
```

The color has an `RR_n` witness iff `G` accepts some cyclic rotation.  This
recurrence proves both coverage and color-specific connectivity when it
returns true; every deletion reverses to two actual inclusion steps through
subsets present in `RR_n`.  Conversely, the final pair of any selected chain
must be one of the three boundary pairs, so the recurrence loses no path.

The checker compares this recurrence with an independent literal
Boolean-lattice path search for every coloring through `n=10`.

### 5.4 The false `n=10` factor obstruction and its hybrid repair

For `n=10`, the plus set `{0,1,2,3,6}` crosses none of the nine seed factors:
their crossing-edge counts are

`3,3,3,3,3,3,1,3,3`.

It nevertheless has the selected hybrid chain order

`3,9,4,2,5,6,7,1,8,0`,

where `9=infinity`.  Its consecutive pairs all cross.  Its interval prefixes
splice prefixes centered at different `r`, so this chain was absent from the
seed menu but present in the literal family.  The earlier factor-only
counterargument is therefore false and is retained as failure knowledge, not
as a construction obstruction.

For context, every one-factorization's **listed** matchings cover every cut
through `n=8`.  If `c_r` is the number of cut edges in factor `r`, then
`sum_r c_r=m^2` and `c_r` has the parity of `m`.  If no factor were perfect,
`c_r<=m-2`, contradicting `m^2>(2m-1)(m-2)` for `m<=4`.  This explains the
small agreement but is only a sufficient seed-path argument.

### 5.5 Exact first failure at `n=22`

The interval recurrence was exhausted over every balanced finite cyclic word
for `q=1,3,...,19`, after sign reversal fixes `infinity` minus.  Every word
reduces, so `RR_n` is a valid 1-balanced-chain family for every even
`n<=20`.  This is a finite exhaustive result, not an asymptotic theorem.

At `q=21`, exactly 21 normalized words fail: the rotations of

`111111110000011100000 = 1^8 0^5 1^3 0^5`.

For the displayed rotation, the reachable start indices at successive odd
interval lengths are

| interval length | reachable starts modulo 21 |
|---:|---|
| 1 | `0,1,2,3,4,5,6,7,13,14,15` |
| 3 | `6,12,14,20` |
| 5 | `5,11,12,13,19` |
| 7 | `4,18` |
| 9 | `3,17` |
| 11 | `2,3,15,16` |
| 13 | none |

Each row follows from the three boundary-pair transitions in Section 5.3.
The empty last row is a compact checkable obstruction: no selected path can
reach the full set.  Thus this exact quadratic family first fails at `n=22`, not at `n=10`.

### 5.6 A four-run countercolor for every even `n>=22`

The obstruction is not isolated.  For every `m>=11`, color `infinity` minus
and take the cyclic finite word

`w_m = 1^(m-3) 0^5 1^3 0^(m-6)`.

It has `m` pluses and `m-1` minuses.  Let `R_l` be the set of starting
indices of reachable cyclic intervals of odd length `l`, with indices modulo
`q=2m-1`.  Directly from the three legal two-symbol extensions,

```text
R_(l+2) = {i-2 : i in R_l and w[i-2] != w[i-1]}
        union {i-1 : i in R_l and w[i-1] != w[i+l]}
        union {i   : i in R_l and w[i+l] != w[i+l+1]}.
```

Substitution in the four constant runs gives

```text
R_3 = {m-5, m+1, m+3, 2m-2}
R_5 = {m-6, m, m+1, m+2, 2m-3}
R_7 = {m-7, 2m-4}
R_9 = {m-8, 2m-5}.
```

For `m=11`, the next rows are the `n=22` rows above and
`R_13=emptyset`.  For `m>=12`,

```text
R_11 = {m-9, m-8, 2m-6};
R_(2t+1) = {2m-t-1}                 for 6<=t<=m-7;
R_(2m-11) = {m+4,m+5};
R_(2m-9) = emptyset.
```

The range in the middle line may be empty.  These identities are verified by
substituting each displayed boundary position into the recurrence; all other
positions lie inside a constant-sign run and generate no child.  Since the
reachable set becomes empty before the full interval length `2m-1`, `w_m`
has no witness.  Therefore `RR_(2m)` fails for every `m>=11`.

This is an obstruction to one exact cyclic-interval construction family.  It
does not rule out a different cyclic order, a polynomial union of several
orders, a richer matching-state DAG, or O01.  A precise retry is to find a
polynomial-size list of ground-set cyclic orders such that every balanced
color word is deque-reducible in at least one order, while counting the union
of all resulting literal interval states.

## 6. Three unsafe ways to merge matching states

### 6.1 Full submatching-union closure

For a fixed perfect matching `M`, a natural order-independent state set is

`U(M)={union A : A subseteq M}`.

Because the matching edges are disjoint, different submatchings have
different unions, so `|U(M)|=2^m` even states.  A menu made from such closures
has at least this many literal states before odd intermediaries are charged.
Thus arbitrary pair-order flexibility for even one matching already destroys
polynomial accounting.  It also does not create coverage: one fixed matching
first fails at `n=4`, by coloring the endpoints of each of its two edges
together.  Restricting pair orders and sharing prefixes across *different*
matchings is the only plausible retry.

### 6.2 Stage-only universal pair selector

Suppose an abstract device has one control node at every stage and offers
every pair as the next label.  It appears to have `m+1` nodes and, on every
balanced coloring, it can repeatedly choose an open pair.  At `n=4` it can
take the same crossing pair twice, so this is not a read-once perfect-matching
path.  If repeated elements are instead forbidden by lifting the stage node
to its literal used support, every even subset occurs: any set of `2j`
elements can be partitioned into `j` pairs.  The support lift therefore has

`sum_j binom(n,2j)=2^(n-1)`

even states.  An external history-dependent legality filter is not an
ordinary DAG state and cannot be omitted from accounting.

This is the exact failure mode behind a description-only routing or sorting
analogy: a small switch/control graph is useful only after the number of
distinct induced supports at every control node is bounded.

### 6.3 Compatibility-signature quotient

For an even subset `S`, define its color signature by

`chi_S(P)=1 iff |P intersect S|=|S|/2`

over balanced plus sets `P`.  Complementary supports have the same signature,
because `P` is balanced.  It is tempting to merge equal signatures.

The operation first fails at `n=4`.  Let

`S={0,1}` and `T={2,3}=U minus S`.

Their signatures agree.  Take the two live source-to-sink paths

`emptyset -> S -> U` and `emptyset -> T -> U`.

Their label sequences are `(S,T)` and `(T,S)`, so both original paths are
read-once perfect matchings.  Merging `S` and `T` also creates the two
cross-splices `(S,S)` and `(T,T)`.  For example the first repeated-label path
is open under plus set `{0,2}`, but it repeats variables `0,1` and cannot
expand to a literal subset chain: starting at support `S`, adding its alleged
second label leaves support `S`, not `U`.

Thus quotienting by color compatibility does not preserve the syntactic
read-once/support semantics, even after dead material is removed.  This does
not assert that the accepted balanced-color domain changes in this four-point
example; it shows that the quotient is not a canonical subset DAG.  Any retry
must retain enough future-support information to prevent prefix and suffix
splicing; the canonical-support lemma shows that literal support is sufficient.

## 8. Reproduction and final boundary

Run from the repository root:

```powershell
python -B experiments/cycle03_check_cp_m_matching.py
```

The standard-library checker independently verifies:

* the cyclic edge factorization and exact literal family size through
  `n=20`;
* the `n=10` separation between failure of every seed factor and success of
  a literal hybrid chain;
* agreement of the deque recurrence with an independent induced-subset-DAG
  search for every coloring through `n=10`;
* exhaustive recurrence coverage for every normalized coloring through
  `n=20`, followed by exactly one 21-rotation failure orbit at `n=22`;
* the closed-form four-run obstruction sets for every sampled
  `11<=m<=50` (the report gives the general recurrence proof);
* the exact `2^(n/2)` color count for a fixed matching;
* the `n=4` compatibility-signature splice; and
* the `2^(n-1)` support lift through `n=16`.

The general arguments are mathematical proof candidates, while the script is
finite corroboration.  None has been checked by Lean or by an external
reviewer.  The useful invariant is the exact literal prefix-union measure;
the missing general result is still a cut-covering induced subset DAG whose
distinct even supports and odd intermediaries are polynomially bounded.
Seed descriptions may undercount hybrid paths, while switch descriptions may
undercount supports.  Asserting either compression without constructing and
accounting for the literal union would restate O01.
